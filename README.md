# HYPE Advisor — профессиональный крипто-советник и сканер рынка

[![Python](https://img.shields.io/badge/python-3.11%2B-blue.svg)](https://www.python.org/downloads/)
[![Tests](https://img.shields.io/badge/tests-51%20passed-brightgreen.svg)]()

**Бот НЕ торгует.** Это аналитический советник: он мониторит рынок 24/7, ищет
скрытые монеты, изучает историю цен, волны, волатильность, фандинг, ликвидации —
и выдаёт профессиональные рекомендации: когда входить, где стоп, где цели.

> Отход от мартингейла: старая стратегия удвоения полностью удалена.
> Никаких усреднений и гридов — только анализ и советы, решение принимает человек.

## 🤖 Что умеет бот

### 1. Мониторинг рынка и поиск скрытых монет
- Сканирует **все фьючерсные инструменты** Bybit (резерв: Binance, MEXC).
- Добавляет источники «скрытых» монет: **CoinGecko тренды и муверы**, монеты из новостей.
- Фильтрует по ликвидности (оборот ≥ $20M/24ч по умолчанию) и рейтингу скрытности.
- Найденные монеты с высоким рейтингом **автоматически добавляются в наблюдение**.

### 2. Глубокий анализ каждой монеты
- **3 таймфрейма**: 15m (точка входа) + 1h (структура) + 4h (макро-тренд).
- **Волны Эллиотта**: импульсы 1–5, коррекции A-B-C, зоны целей.
- **Волатильность**: ATR-процентиль, squeeze (сжатие BB внутри Keltner), реализованная волатильность.
- **Структура рынка**: ADX/DI, свинг-уровни, VWAP, SuperTrend.
- **Моментум**: RSI, MACD, стохастик, OBV, CVD (прокси дельты), z-score объёма.
- **Деривативы**: фандинг и его тренд (перегрев лонгов/шортов), свежие ликвидации.

### 3. Профессиональные советы: вход и выход
- Направление: **LONG / SHORT / WAIT** (ожидание — полноценная рекомендация).
- **Зона входа** по фибо-ретрейсментам (0.382–0.618) с учётом ATR.
- **Стоп-лосс** за структурным минимумом/максимумом.
- **Цели** по фибо-расширениям (1.0 / 1.618) и R-кратности.
- **R:R**, рекомендуемое **плечо** (ограничено волатильностью), **% риска**.
- Уверенность сценария, список «почему» и список рисков, что отменит идею.

### 4. Графики
- Свечи + EMA + SuperTrend + зона входа + стоп + цели + RSI + объём.
- Панель найденных монет по рейтингу.

### 5. Уведомления и сопровождение
- Telegram: алерты по сигналам выше порога, события «стоп сработал / цель достигнута».
- Fear & Greed индекс, новости с сентиментом.
- Бумажные позиции по вашим советам (журнал входов/выходов).

### 6. Веб-дашборд
Живая HTML-страница + JSON API: наблюдение, находки сканера, позиции, новости.

## 🚀 Быстрый старт

```bash
python -m venv .venv && source .venv/bin/activate
pip install -r requirements.txt

# скопируйте и заполните настройки (опционально)
cp .env.example .env

# запуск всего: дашборд + сканер + наблюдение + Telegram
python main.py

# или по частям
python main.py scan                    # разовый скан скрытых монет
python main.py analyze SOLUSDT         # разовый анализ одной монеты
python main.py watch                   # только фоновое наблюдение
python main.py api                     # только веб-дашборд (порт 8000)
```

Тесты и линтер:

```bash
make test     # pytest
make lint     # ruff
```

## 📱 Telegram-команды

| Команда | Описание |
|---|---|
| `/start`, `/help` | Справка |
| `/watch` | Текущее наблюдение и рекомендации |
| `/scan` | Запустить скан скрытых монет (1–3 мин) |
| `/gems` | Последние находки сканера |
| `/signal SOLUSDT` | Полный анализ монеты + график + план входа |
| `/chart SOLUSDT` | Только график |
| `/positions` | Бумажные позиции по советам |
| `/fear` | Fear & Greed индекс |
| `/news` | Свежие новости с сентиментом |
| `/add SYMBOL`, `/del SYMBOL` | Управление наблюдением |

Бот сам присылает алерт, когда монета из наблюдения набирает рейтинг
≥ `ALERT_MIN_SCORE` (по умолчанию 70), и события по позициям
(стоп-лосс / цель достигнута).

## ☁️ Деплой на Railway

1. Подключите репозиторий в Railway (или `railway up`).
2. Railway сам найдёт `Dockerfile`. Либо используйте Procfile: `worker: python main.py`.
3. Задайте переменные (Variables) — **совместимы со старым ботом**:
   - `TELEGRAM_TOKEN` (или новое имя `TELEGRAM_BOT_TOKEN`) — токен бота;
   - `TELEGRAM_CHAT_ID` (или `TELEGRAM_ADMIN_CHAT_ID`) — ваш чат для алертов;
   - `BYBIT_API_KEY` / `BYBIT_API_SECRET` — Bybit (для публичных данных можно без них);
   - `MARKET_DATA_MODE=auto` — на Railway с доступом к биржам бот автоматически
     работает с **реальными данными**; демо включается только если биржи недоступны.
4. Готово — бот запустит наблюдение, сканер и Telegram.

## 🔀 Режимы данных: live / demo

- **live** — Bybit → Binance → MEXC → CoinGecko (только публичные данные; ключи не нужны).
- **demo** — детерминированный синтетический рынок: 90 монет трёх эшелонов,
  сценарии «накопление → памп/дамп → распределение», реалистичные объёмы и фандинг.
  Нужен для тестов и запуска там, где биржи заблокированы.
- **auto** (по умолчанию) — начинает с live и **автоматически** переключается на demo
  при недоступности бирж, с предупреждением в логах, Telegram и на дашборде.

⚠️ В demo-режиме советы **не являются** реальными сигналами.
